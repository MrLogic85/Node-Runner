Opened by **Train** or **Resume training** on the Creation screen, and by nothing else. It has three choices and one button.

- **Shadows** (slider, 1 to 32): how many ghost copies race at the same time. The value is shown large in `readout-lg` beside the label, with the range ends under the track. More shadows means more variety per generation but a heavier phone.
- **Run length** (slider, 5 to 60 s): how long each generation runs.
- **Map**: a horizontal list of every map. Exactly one is unlocked at first (Flat ground); the rest are dashed, dimmed and show a lock with the word "Locked". Selecting a locked map opens Achievements at the achievement that unlocks it. The selected map has an `accent` border, a check and its label.

Sliders are a 6px track with a 28px thumb in a 36px hit row, and the value updates live while dragging; tapping the value opens a number pad for an exact number. The top bar has the mode switch, **Train** (learns, saves progress) or **Simulate** (just runs the saved brain, no learning), and the one primary, **Start**, which opens Training. The previous choices are remembered per creation, so Resume is one tap.
